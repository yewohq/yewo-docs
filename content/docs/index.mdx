Yewo is an AI testing agent for Android and iOS apps. Describe a user journey in
plain language and Yewo operates the real app, checks what happened, and produces
an evidence-backed report.

## Which one do I need?

The CLI is the whole product on its own: it drives a local emulator or simulator
and writes reports to disk. Yewo Cloud adds hosted devices, run history across
builds, and a place for a team to review findings together.

<Callout type="warn">
  Yewo is alpha software. Expect breaking changes until its public interface is stable.
</Callout>
